## SALES UX PRINCIPLES

The sales landing page should communicate:

**More Leads → Better Targeting → Less Canvassing → More Closing**

Make Token consumption transparent.

Always show:
- Token cost
- Expected lead information
- Unlock confirmation
- Remaining Token balance

Never make the Token system feel deceptive.

The user must understand exactly what happens before clicking "Unlock".
